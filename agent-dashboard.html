How to connect your Claude project or chat
  1. Claude.ai chats and Projects can’t be opened by other apps, so this uses the Claude API instead. Get a key at console.anthropic.com under API keys. API billing is separate from a Claude Pro plan: add a little credit and set a monthly spend limit.
  2. Click Connect (top right), paste the key and pick a model. For ChatGPT, use a key from platform.openai.com.
  3. Open your project on claude.ai (for example, Portfolio). Copy its instructions and any key notes into Project context below. The operator here then works from the same brief.
  4. Copy the project or chat address from your browser bar into Linked Claude or ChatGPT page. You get a button to jump back to it.
  5. Write the instruction and start. Steer it in the conversation, and use Log a run to record work that’s been done.

Keys and workflows are stored only in this browser. Don’t connect on a shared computer, and use Clear keys if you do.
