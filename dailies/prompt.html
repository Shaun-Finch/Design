Write my end-of-day Dailies round-up.

Look back over everything we worked on together today in this conversation and summarise it in the exact format below, so I can paste it straight into my Dailies dashboard.

RULES
- Keep the field names exactly as written, one per line, in this order.
- Write one block for each task we worked on today. Start every block with the line DAILIES.
- Status must be one of: Not started, In progress, In review, Blocked, Done.
- Priority must be one of: High, Medium, Low.
- Round is the number of this update for the task: 1 the first time I report on it, then 2, 3 and so on. If you don't know, leave it blank.
- Next step is the single next action, with a day if we agreed one.
- Keep each line under 25 words. Be specific: name the file, tool, number or person.
- Only include what actually happened or was decided today. Don't invent progress.
- If you don't know my name, sector or a value, leave the square brackets in so I can fill them in.
- No introduction, no sign-off, no tables, no extra headings.

FORMAT

DAILIES
Name: [your name]
Date: [today's date as YYYY-MM-DD]
Task: [the piece of work this update covers]
Sector: [your team or area, e.g. UX/UI, Video, Marketing, Engineering]
Status: [Not started / In progress / In review / Blocked / Done]
Priority: [High / Medium / Low]
Round: [1, 2, 3…]
Next step: [the single next action]
Update: [one or two sentences on what happened today]
Blocker: [what's stopping progress and who it's waiting on, or None]
